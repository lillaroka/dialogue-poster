# Dialogue Poster

将对话内容生成精美长图。

## 功能

- **对话编辑** — 左右双角色对话，支持拖拽排序
- **多页 / 长图** — 分页模式（1440x2400 / 1080x1920）或长图模式（1080px 宽，高度自适应）
- **10 种配色预设** — 清新薄荷、海洋蓝、珊瑚橙、薰衣草、暗夜、玫瑰金、抹茶、琥珀、石墨、深海
- **5 种背景纹理** — 圆点、横线、纸张暗角、噪点，纯 CSS 实现
- **头像 & 名称** — 自定义说话人头像与名称
- **高清导出** — PNG 2x 分辨率，支持单页或批量导出

## 技术栈

React · TypeScript · Vite · Zustand · Tailwind CSS · @dnd-kit · html-to-image

## 开发

```bash
npm install
npm run dev
```

浏览器打开 Vite 提示的本地地址即可。

## 构建

```bash
npm run build
```

产物输出到 `dist/` 目录。
